# 🔷 Verilog Assignments

A collection of Verilog HDL programs developed as part of my learning and practice in **Digital Logic Design, Verilog HDL, and VLSI Design**.

This repository contains various combinational and sequential digital circuits along with their corresponding **testbenches** for simulation and waveform verification.

---

## 📌 About This Repository

The purpose of this repository is to build a strong foundation in:

- Digital Logic Design
- Verilog HDL
- RTL Design
- Testbench Development
- Simulation and Waveform Analysis
- Fundamental VLSI Concepts

Each design is implemented using Verilog HDL and can be simulated using standard HDL simulation tools.
